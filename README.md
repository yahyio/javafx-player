# Lumen — JavaFX Music Player

Desktop music player with a realtime 48-band audio spectrum visualizer.

## Features

- Playlist sidebar with play/pause/next/previous
- Seek and volume sliders
- 48-band realtime spectrum driven by JavaFX AudioSpectrumListener
- Gradient canvas visualizer
- Dark UI styled entirely in code — no FXML

## Tech Stack

Java · JavaFX · Gradle

## Run

```bash
./gradlew run
```

Requires a JDK with JavaFX (Oracle JDK 8, or OpenJFX modules on 11+).
